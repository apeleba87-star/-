- `캡처.png` — **예시** 이미지 (하단에 「예시 · 실제 게시 전 본인 캡처로 교체」)

전체 설명(A~Z): `00-플레이북-AtoZ.md`

## 중요

카페 신뢰가 자산이다. 예시 캡처를 **실제 문의인 척** 올리지 말 것.  
가능하면 같은 구도의 **본인 실캡처**로 교체한 뒤 게시한다.
