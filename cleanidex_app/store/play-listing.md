## 짧은 설명 (80자 이내)

```
오염·세제만 고르면 희석과 청소 순서를 바로 알려주는 사용법 앱
```

## 긴 설명

```
클린아이덱스는 얼룩과 세제에 맞는 청소 사용법을 빠르게 찾아 주는 앱입니다.

• 오염으로 찾기 — 요석, 곰팡이, 기름때 등
• 세제로 찾기 — 희석비·pH·주의사항을 한눈에
• 사용법 화면 — 단계별 순서와 주의만 남긴 실행형 가이드

웹 클린아이덱스(cleanindex.kr)의 청소 지식 중, 현장에서 바로 쓰는 부분만 담았습니다.
입찰·채용·광고 기능은 포함하지 않습니다.
```

## 스크린샷 체크리스트 (최소 2장, 권장 3장)

1. **홈** — “무엇을 지울까요?” + 빠른 오염 칩
2. **세제 상세** — 희석이 크게 보이는 히어로
3. **사용법** — 번호 스텝 + 희석 카드

촬영: `flutter run` 후 에뮬레이터/실기기 캡처.  
권장 해상도: 1080×1920 또는 Play Console 가이드에 맞는 폰 세로.

## 내부 테스트 트랙

1. Play Console → 앱 만들기 → `com.cleanidex.cleanidex_app`
2. `flutter build appbundle --release` (서명 키 준비 후)
3. 내부 테스트 트랙에 AAB 업로드
4. 테스터 이메일 목록에 현장/운영 인원 추가
5. 확인 항목: 검색 → 사용법 도달, 희석 가독성, 오프라인(번들) 동작

## 개인정보

MVP는 로그인·추적 SDK 미포함(기본).  
Firebase Analytics를 나중에 넣으면 Play 데이터 안전 양식에 고지.

## 웹 연계

- 제품: `https://cleanindex.kr/products/{id}`
- 사용법: `https://cleanindex.kr/cleaning/{slug}`
- 견적 문의는 앱 밖 브라우저로만 연결 (MVP 범위 외)
