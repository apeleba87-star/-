# 클린아이덱스 마케팅 플레이북 (청소업모여라)

**대상 채널:** 당근 카페 「청소업모여라」(초보 다수)  
**제품:** 클린아이덱스 현장 앱 + 웹 AI 블로그  
**원칙:** “이 서비스가 좋습니다”가 아니라, **쓴 뒤에만 생기는 장면**(문의 카톡, 상위 노출, 바쁜 일정, 일 끝난 뒤 한 잔)을 보여 준다.  
**자동차 광고 비유:** 마력이 아니라 시원한 물·여유로운 커피. 우리 쪽 물·커피 = **카톡 문의 / 검색 노출 / 견적 전화 / 채워진 달력**.

이 문서는 **체크리스트 → 실제 앱·웹 모습(A~Z) → 1·2주차 게시 문안 → 운영 규칙** 순이다.

---

## 0. 한 줄 포지션

> 청소 글 잘 쓰는 법이 아니라,  
> **「일 끝나고 나서, 일이 다시 들어오는 느낌」**을 파는 브랜드.

카페에서는 **같은 업종 사람의 짧은 일기**로 말한다. 툴 이름·구독 권유는 본문에 거의 넣지 않는다. “어떻게 하세요?”가 오면 DM으로만 안내한다.

## 1. 촬영·게시 체크리스트 (필수)

### 1-1. 올리기 전에 가릴 것

| 가리기 | 방법 |
|--------|------|
| 고객 실명·주소 상세 | 가림띠 / 잘라내기 |
| 전화번호·카톡 ID | 가림 |
| 얼굴·차량번호·현관 호수 | 가림 또는 크롭 |
| 금액이 민감하면 | 금액 줄만 가림 |
| **앱·웹 UI가 화면의 주인공** | 피함. 카톡·네이버 검색·전화기록·전후 사진이 주인공 |

앱 화면을 꼭 보여줄 때는 **아주 작게·구석에만**, 또는 “저녁에 올라가 있더라”처럼 **결과만** 말한다.

### 1-2. 장면별 찍을 것 (물 한 잔 소재)

| 코드 | 장면 | 찍을 화면 | 비고 |
|------|------|-----------|------|
| S1 | 문의 카톡 | “블로그/글 보고 연락” 문장 | 이름·번호 가림 |
| S2 | 검색 상위 | 네이버 `동네+청소` 검색 결과 | 본인 글 보이게 |
| S3 | 전화 | 수신·부재중 목록 | 번호 가림 |
| S4 | 전후 | 현장 전·후 1쌍 | 글/툴 설명 없이 |
| S5 | 달력 | 이번 주·이번 달 일정 | 개인정보 가림 |
| S6 | 여유 | 차 안 커피·편의점 음료 | 일 끝난 뒤 |
| S7 | 구체 문의 | 면적·동·입주일 적힌 문의 | 가림 후 |
| S8 | 주말 알림 | 쉬는 날 아침 카톡 | 내용 일부 가림 가능 |
| S9 | (선택) 보고서 | 고객에게 보낸 링크 미리보기 | UI 과다 노출 금지 |
| S10 | (선택) 현황 | 앱 **현황** 탭 숫자 | “이번 달 현장 N” 정도만 |

### 1-3. 게시 운영 체크리스트

- [ ] 이번 주 올릴 요일 정함 (권장: **월·수·금** 또는 주 2~3회)
- [ ] 글마다 **장면 사진 1장** 준비 (문장만인 글은 광고로 읽힘)
- [ ] 본문에 “최고 / 필수 / 구독 / 자동완성” 같은 **판매 단어 없음**
- [ ] 마지막에 링크·앱 이름 **없음** (질문 오면 DM)
- [ ] 실제 본인(또는 동의 받은 회원) 사례만 사용
- [ ] 허위 문의·조작 캡처 금지 (카페 신뢰 = 자산)

### 1-4. “어떻게 하세요?” DM 답 템플릿

```
현장 끝날 때마다 전후 사진만 남겨 두고,
그걸 글로 올려 두는 중이에요.
쓰는 도구·순서는 원하시면 짧게 적어 드릴게요.
```

필요 시 한 줄만 추가:

```
앱에서 사진 → PC에서 글·네이버 붙여넣기 흐름입니다.
```

## 2. 실제 서비스 모습 A~Z (앱 + 웹)

마케팅 문안을 쓸 때 **과장하지 않기 위한 사실 기준**이다.  
클린아이덱스는 네이버에 **대신 올리지 않는다**. 사용자가 복사·붙여넣기로 직접 게시한다.

### A. 로그인 (앱)

- 화면: 브랜드 로고 + **클린아이덱스** + **「현장 전후 사진 · AI 블로그」**
- 이메일·비밀번호 → **로그인**
- 이후 기본 탭: **현장**

### B. 하단 탭 3개

| 탭 | 하는 일 |
|----|---------|
| **현장** | 작업 목록·만들기·사진 |
| **현황** | 이번 달 매출·현장 수 등 (웹과 같은 감각의 요약) |
| **내 정보** | 계정 / 업체 기본정보 / 이용 현황 / 로그아웃 |

### C. 현장 목록 · 버킷

- **현장 만들기** 버튼
- 안내: 원본은 **14일** 지나면 미리보기만 남음
- 세그먼트:
  - **쓰는중** — PC에서 글 작성·다듬는 중
  - **완료** — 글쓰기 마친 현장
  - **기타** — 아직 글 없음·보관. **삭제하기는 여기만**
- 카드: 제목, `장소 N곳 · 전후 N짝`, 글 상태 배지(글 없음 / 글 쓰는 중 / 네이버 준비됨 / 글쓰기 완료 / 보관)

### D. 기타에서만 삭제

- **삭제하기** → 확인 대화상자 → soft-delete (목록에서 사라짐)
- 쓰는중·완료 탭에는 삭제 버튼 없음

### E. 현장 만들기

- 현장 이름(예: 동 이름), 청소 종류(입주·거주·특수 등)
- 만든 뒤 장소·사진 화면으로 이동

### F. 현장 상세 (장소 · 전후)

- **현장 정보** 진입
- 장소별: 청소 전 찍기 / 청소 후 찍기 / 다시 찍기 / 오염 상태 적기
- **장소 추가**
- 사진이 있으면: **네이버에 넣기**(앱 쪽 사진 가이드), **청소 보고서**

### G. 현장 정보

- 시·도 / 구·군 / 동, 건물 유형, 평수, 인원, 작업 시간·날짜, **금액(선택, 블로그에 안 넣음)**, 설명
- 웹 작업 정보와 맞추는 메타

### H. 카메라

- 촬영 → 이 사진 사용 / 다시 찍기
- **후** 찍을 때 **전** 사진을 참고(오버레이)할 수 있음
- 폰 저장 + 서버 업로드 (용량 제한 있음)

### I. 앱 「네이버에 넣기」(사진 붙이기 가이드)

- 앨범·폴더·파일명 안내
- 문단 **복사** → 네이버에 사용자가 직접 붙여넣기  
- (웹의 AI 글 이전 플로우와는 별도. 앱은 갤러리 사진 쪽 보조)

### J. 청소 보고서 · 고객 링크

- 장소별 전·후 보고서 화면
- **고객에게 링크 보내기** → 카카오 등에 붙일 문구 + 공개 보고서 URL  
- 고객은 로그인 없이 전후 보고서 열람 (검색 노출용 페이지가 아님)

### K. 현황 · 내 정보

- **현황:** 월 매출, 현장 수, 금액 입력 여부, 건당·인시당 감각의 숫자
- **내 정보:** 계정(별명·연락처 등), **업체 기본정보**(AI 글 톤·서비스), **이용 현황**(구독·한도는 웹 안내)

### L. 웹 진입

- `https://www.cleanidex.co.kr/ai-blog` (또는 동일 경로)
- 상단: 로고 + **내 블로그 글** / **업체 소개** / **구독** + 이번 달 작성 편수

### M. 「내 블로그 글」 홈

- 흐름 카피 감각: 작업 등록 → 사진 맞추기 → 네이버에 올리기
- 할 일 카드: 사진 남음 / 글 쓰기 / 작성 중 / 네이버에 올리기 / 완료
- 매출·효율 요약도 함께 볼 수 있음

### N. 프로젝트(작업) 워크스페이스

| 단계 | 탭 | 사용자 행동 |
|------|-----|-------------|
| 1 | **작업 정보** | 어디·무슨 청소인지 저장 |
| 2 | **사진** | 앱에서 올린 전후 확인, 또는 PC에서 전후 맞춤 |
| 3·4 | **글 · 네이버** | AI로 글 만들기 → 고치기 → 네이버에 옮기기 |

작업 삭제(웹) 가능.

### O. 글 만들기 → 고치기 → 네이버

- 톤: 후기처럼 / 전문가처럼 / 짧게 등
- **메인 키워드**(지역 검색용)
- AI는 장소·오염 등 텍스트 정보를 참고 (사진 파일 자체를 학습용으로 보내지 않는 설계)
- 옮기기: 제목·본문 복사, 사진 폴더 준비, **네이버에서 직접 게시**
- 명시 사실: **클린아이덱스는 네이버에 대신 올리지 않음**

### P. 업체 소개 · 구독

- 업체명·지역·서비스·글 스타일·플레이스 URL 등 → 초안에 반영
- 구독·월 작성 한도·결제/해지는 웹에서

### Q. 사용자가 실제로 얻는 결과 (마케팅에 쓸 수 있는 것만)

| 결과 | 출처 |
|------|------|
| 네이버에 올릴 **글 초안** (지역·전후 스토리) | 웹 AI → 사용자 게시 |
| 동네 검색에 걸릴 **소재** | 동·구 + 서비스 + 키워드 |
| 고객에게 보내는 **전후 보고서 링크** | 앱 |
| 현장 전후 **사진 자산** | 앱 → 서버(원본 보관 기간 있음) |
| **이번 달 현장·매출 감각** | 앱 현황 / 웹 실적 |

### R. 권장 하루 흐름 (A→Z 압축)

1. 현장에서 앱으로 **전후 촬영** (+ 오염·현장 정보)  
2. (선택) 고객에게 **보고서 링크**  
3. PC에서 같은 작업 열어 **AI 글 → 네이버 붙여넣기**  
4. 며칠 뒤 **문의 카톡 / 검색 노출**이 생기면 그걸 카페에 올림  
5. **현황**으로 달이 어떻게 채워졌는지 확인  

### S. 카페 초보에게 말하면 안 되는 과장

- “누르면 네이버에 자동 게시”
- “상위 노출 보장”
- “계약 보장”
- “사진만 찍으면 끝”(실제로는 **네이버에 붙여 넣는 한 단계**가 있음)

### T. 카페 초보에게 말해도 되는 사실

- 현장 끝나며 **전후만 남기면** 나중에 글 재료가 된다  
- 글은 **PC에서 다듬고**, 네이버는 **직접** 올린다  
- 고객에게는 **전후 보고서 링크**로 신뢰를 줄 수 있다  
- 문의·노출은 **올린 뒤**에 생기는 일이라, 그 장면을 기록한다  

### U. 브랜드 비주얼 (실제)

- 마크: 파란 **C** + 스파클(별)  
- 앱 아이콘: 파란 그라데이션 바탕 + 흰 C  
- 웹 헤더·AI 블로그 내비·앱 로그인/앱바에 동일 계열 로고 사용  

### V. 「청소업모여라」 채널 특성

- 초보 다수 → **일기·결과 장면**이 “강의·세일즈”보다 잘 먹음  
- 운영자(본인) 글이므로 **실제 캡처**가 가장 센 증거  
- 주 2~3회면 충분. 매일 세일즈하면 카페가 광고판이 됨  

### W. 콘텐츠 공식 (반복)

`실제 캡처 1장` + `그날 문장 2~3줄` + `감정 한 줄`  
예: 문의가 와서 → “그날은 좀 다르게 끝납니다.”

### X. 금지 공식

`기능 나열` + `지금 가입` + `링크 박기`  
예: “AI가 자동으로… 구독하면…”

### Y. 성공 지표 (카페용, 가볍게)

- 게시당 “어떻게 해요?” DM·댓글 수  
- 실제 체험·온보딩으로 이어진 수 (숫자만 조용히 기록)  
- 허위 없이 **쌓인 장면 캡처 폴더** 개수 (자산)

### Z. 이 문서와 제품의 관계

- 제품 개선은 코드/앱에서  
- 카페는 **제품 설명서가 아니라 결과 일기장**  
- 기능이 바뀌면 이 문서 **§2 A~Z**만 먼저 고치고, 문안은 결과에 맞게 유지

## 3. 1주차 게시 문안 (월~토)

각 글: **사진 코드** + **본문**. 제목은 생략해도 된다.

### 1주차 · 월 (S1 카톡)

> 오늘 오후 2시.  
> “입주청소 가능할까요?”  
>  
> 아침에 올린 글 보고 왔대요.  
> 이런 문자가 오면, 그날은 좀 다르게 끝납니다.

### 1주차 · 화 (S2 검색)

> 동네 이름 + 청소 쳐봤습니다.  
>  
> 위에 떠 있길래 캡처해 뒀어요.  
> 누가 보라고 올린 건 아닌데, 혼자 보고 웃었습니다.

### 1주차 · 수 (S3 전화)

> 평일 오후인데 벨이 세 번.  
>  
> 전부 “블로그 보고 연락드렸습니다.”  
> 청소는 몸으로 하는데, 일은 이렇게 들어오더라고요.

### 1주차 · 목 (S4 전후)

> 오늘은 글 이야기 말고,  
> 이 장면만 남깁니다.  
>  
> 찍을 땐 그냥 기록인데  
> 나중에 보면 그게 일이 됩니다.

### 1주차 · 금 (S5 달력)

> 이번 주 현장 표시해 보니  
> 빈칸이 생각보다 적네요.  
>  
> 예전이랑 비교하면  
> “문의가 와서” 채워진 칸이 많습니다.

### 1주차 · 토 (S6 여유)

> 울퉁불퉁한 하루였는데  
> 마지막은 이게 남았습니다.  
>  
> 일 잘했다는 증명보다,  
> 내일 또 전화 올 수도 있다는 느낌.

## 4. 2주차 게시 문안

### 2주차 · 월 (S1 “보고 연락” 확대)

> 제일 좋아하는 문장.  
>  
> “○○에 올려두신 거 보고 연락드렸습니다.”  
>  
> 이 한 줄이면,  
> 오늘 한 일이 밖으로 나갔다는 뜻입니다.

### 2주차 · 화 (S2 검색 변화)

> 예전에 안 보이던 검색어인데  
> 요즘은 가끔 걸립니다.  
>  
> 대단한 비법은 없고  
> 현장 끝날 때마다 하나씩 남긴 결과예요.

### 2주차 · 수 (S7 구체 문의)

> “얼마예요?”만 오는 날도 있고  
> 이렇게 자세한 날이 있습니다.  
>  
> 자세한 문의가 오면  
> 대화가 짧아지고, 성사는 빨라집니다.

### 2주차 · 목 (사진만 찍은 날 — 결과만)

> 오늘은 글 쓸 시간이 없었어요.  
> 사진만 찍고 나왔습니다.  
>  
> 저녁에 보니 글이 올라가 있고  
> 그게 또 일이 되더라고요.

(앱·웹 화면을 크게 넣지 말 것. “저녁에 올라가 있더라”가 포인트.)

### 2주차 · 금 (초보 시절 vs 오늘, S5)

> 처음엔 일 구하는 게 일이었습니다.  
>  
> 지금은  
> “올렸더니 연락 왔다”가  
> 가끔 일정이 됩니다.  
>  
> 초보일 때 듣고 싶었던 말만 적어둡니다.

### 2주차 · 토 (S8 주말 알림)

> 쉬는 날 아침에 울리면  
> 잠깐 귀찮다가,  
> 금방 고맙습니다.  
>  
> 주말에 오는 문의는  
> “급해요”인 경우가 많아요.
